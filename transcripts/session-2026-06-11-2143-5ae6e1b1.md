### JJ _02:43 PM PT_

Great question from the course participant. Here's a clear answer to what they're asking:

**Resuming past conversations in Claude Code**

Claude Code does save conversation history. In the terminal, you can access it with:

```bash
claude --resume
```

This shows a list of recent conversations with timestamps and lets you pick one to continue. Each entry shows the project folder it was started in.

If they're in VS Code using the Claude Code extension, the same history is accessible -- there's typically a history panel or they can use the `/resume` command in the chat input.

**On the summary question**

The summary they see at the top of a resumed conversation is auto-generated from the previous session. It shows what was discussed so they can orient quickly without re-reading everything. This happens automatically on resume -- they don't need to do anything special to get it.

**Their token-saving approach is correct**

Opening a new conversation per task is smart. Each conversation only sends its own history back to Claude, not the history from other tabs. So five parallel task conversations in one customer folder = five separate, efficient contexts. This is exactly how Claude Code is meant to be used.

**One thing worth noting for the course**

In the terminal workflow, `claude --resume` makes the multi-conversation approach even cleaner because the picker shows all conversations with their folder context. VS Code extension users get the same benefit through the history panel.

Is this a question that came in for the course? If so, this answer might be worth adding as a FAQ entry in the course content.
